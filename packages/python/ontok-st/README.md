# ontok-st

The type-native Python reference package for `spec/ontok-st.xml`.

## Namespace

`ontok.st`

## Responsibility

ST realizes Semantic Topology: the evolving structure of meaning among independently declared Concepts. It depends one-way on `ontok-core` and remains independent of other extension packages.

## Realization

The package structure exists, but implementation is intentionally deferred until Core's meaning primitives are realized and this module's specification is constructed in Python.
